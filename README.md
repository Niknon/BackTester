# BackTester — симулятор биржи Bybit на исторических данных

Веб-терминал в стиле Bybit, в котором торговля идёт **на истории**: время симуляции
движется свеча за свечой (с паузой, шагами и перемоткой), а будущее скрыто. Можно
торговать вручную, запускать торговых ботов и прогонять собственные стратегии.

## Возможности

### Фьючерсы (USDT-перпетуалы)
- Плечо от 1x до максимума Bybit для инструмента, **кросс** и **изолированная** маржа.
- Ордера: лимитные, рыночные, условные (стоп-маркет / стоп-лимит), GTC / IOC / FOK / Post-Only, Reduce-Only.
- TP/SL при открытии и на позицию, **трейлинг-стоп**, частичное и полное закрытие (по рынку и лимитом), изменение маржи изолированной позиции.
- Комиссии мейкер/тейкер (по умолчанию как у Bybit VIP0: 0.02% / 0.055%), проскальзывание.
- **Funding** по реальной истории ставок (выплаты каждые 8 ч или по фактическому расписанию).
- **Ликвидации**: изолированные — по цене ликвидации с потерей маржи; кросс — по коэффициенту поддерживающей маржи аккаунта (MMR первого тира = IMR<sub>min</sub>/2, как у Bybit).
- Единый торговый аккаунт (UTA): капитал, доступный баланс, IM/MM, MMR.

### TradFi-фьючерсы (USDT-перпетуалы с плечом)
- **Акции**: AAPL, MSFT, GOOGL, AMZN, META, NFLX, AMD, AVGO, TSM, ASML, ARM, MRVL, SMCI, INTC, ORCL, PLTR, CRM, ADBE, CSCO, IBM, SHOP, COIN, HOOD, MSTR, CRCL, MARA, RIVN, BRKB, LLY, UNH, JNJ, MRK, KO, WMT, XOM, GME + NVDA, TSLA, MU, SKHY, SNDK, SPCX.
- **ETF и индексы**: SPY, QQQ, IWM, TQQQ, SQQQ, SOXL, XLE, XBI, USO, US500 (S&P 500), US100 (Nasdaq-100).
- **Сырьё**: золото XAU, серебро XAG, платина XPT, палладий XPD, медь XCU, нефть WTI (CL), газ NG.
- Всё как у обычных перпетуалов: плечо, кросс/изолированная маржа, TP/SL, funding, ликвидации, фьючерсные гриды, мартингейл, комбо. Источник — Bybit, фолбэк — те же перпетуалы OKX (большинство листинговано в 2026 г.).

### TradFi на споте: токенизированные акции (xStocks) и золото
- Раздел TradFi спота Bybit: **xStocks** — токены акций и ETF (AAPLX, MSFTX, NVDAX, GOOGLX, AMZNX, METAX, TSLAX, NFLXX, AMDX, AVGOX, ORCLX, PLTRX, COINX, HOODX, MSTRX, CRCLX, INTCX, MRVLX, CRMX, ADBEX, CSCOX, IBMX, LLYX, UNHX, JNJX, MRKX, KOX, WMTX, XOMX, GMEX, MCDX, JPMX, SPYX, QQQX, IWMX, TQQQX, GLDX) и токены золота **XAUT**, **PAXG**.
- Торгуются **только на споте** за USDT, 24/7, без плеча и funding (как на Bybit); доступны спотовый грид и DCA. Перпетуалы, фьючерсные боты и комбо на них не открываются — движок отклоняет такие ордера с понятным сообщением.
- Свечи — со спота Bybit (`category=spot`, история с июля 2025); резервный источник — USDT-перпетуал OKX на ту же акцию (≈ с марта 2026). В синтетике у акций спокойные выходные (биржа закрыта).
- Спот-форма умеет покупать **на сумму в USDT** («купить AAPL на 500$»).

### Опционы
- Все базовые активы опционов Bybit (на сентябрь 2026):
  - крипто: **BTC, ETH, SOL, XRP, DOGE, MNT, HYPE**;
  - **Perp Options** на TradFi-перпетуалы: **NVDA, TSLA, QQQ, SPCX (SpaceX), SOXL, MU, SKHY (SK Hynix), SNDK (SanDisk)**.
- Экспирации как у Bybit: 3 дневные, 3 недельные (пятница), 3 месячные (последняя пятница), для BTC/ETH — квартальные; всё в 08:00 UTC. Символы вида `BTC-26SEP26-90000-C-USDT`.
- Цепочка страйков (bid / mark / ask, IV, дельта, гамма, вега, тета). Клик в любом месте строки выбирает колл (левая половина) или пут (правая); тикет справа: тип колл/пут, экспирация, страйк (◀ ▶, ITM/ATM/OTM), две большие кнопки **Купить по Ask / Продать по Bid**, объяснение сделки простыми словами и PnL до открытия.
- Цена — Блэк–Шоулз; IV = реализованная волатильность (7д/30д, без заглядывания в будущее) × премия + временная структура + улыбка (скос и кривизна). Для BTC/ETH можно использовать индекс **DVOL** (Deribit).
- Покупка и продажа (шорт) опционов с маржой, европейская экспирация с поставкой деньгами и комиссией поставки.
- Профиль выплат (на экспирации и T+0), греки портфеля, **конструктор стратегий** (стрэддл, стрэнгл, спреды, железный кондор, бабочка, риск-реверсал…), график улыбки и временной структуры IV.

### Торговые боты (каждый — в изолированном суб-аккаунте)
- **Спотовый грид** — арифметическая/геометрическая сетка, цена запуска, TP/SL, продажа монет при остановке.
- **Фьючерсный грид** — лонг / шорт / нейтральный, с плечом, TP/SL по цене и по ROI.
- **Фьючерсный комбо-бот (ребалансировка)** — портфель лонг/шорт перпетуалов с целевыми весами; ребалансировка по времени или по отклонению весов.
- **DCA** — регулярные покупки с фиксацией прибыли.
- **Фьючерсный мартингейл** — усреднения с множителем, TP от средней, цикличность.
- «AI-параметры» (диапазон и число сеток по недавней истории — без будущих данных).
- **Быстрый бэктест бота** в отдельной копии биржи (с текущего момента или с начала периода) — с отчётом и кривой капитала.
- **Сетка на графике**: при настройке грид-бота график сразу показывает все уровни (покупки / продажи / пустой уровень), границы, цену запуска и TP/SL — границы можно **тянуть мышью**. Для мартингейла — уровни усреднений и средняя, для DCA — «покупать ниже». Во вкладке «Запущенные» — график выбранного бота с живыми ордерами сетки, его позицией и сделками; в «Подробнее» → «На графике» — то же для остановленных ботов.

### Лаборатория стратегий
- Редактор JavaScript (CodeMirror) с шаблонами: пересечение EMA, RSI, пробой Дончиана с ATR-трейлингом, Supertrend, Bollinger + MACD.
- API: индикаторы (`ctx.ta.*`), ордера (`ctx.buy/sell/long/short/exit`), TP/SL, трейлинг, плечо, логи и плоты.
- Исполнение на базовом интервале с тем же движком (комиссии, funding, ликвидации).
- **Оптимизация параметров** перебором по сетке с сортировкой по Шарпу / доходности / PF / Калмару.

### Визуал и инструменты
- Графики TradingView lightweight-charts v5: свечи / Хейкен-Аши / бары / линия, таймфреймы от базового до недели.
- Индикаторы: MA, EMA, Bollinger, VWAP, SuperTrend, Donchian, объём, RSI, MACD, Stochastic, ATR, CCI, OBV, ADX/DMI (с параметрами, в отдельных панелях).
- Рисование: трендовая, луч, горизонталь, вертикаль, прямоугольник, Фибоначчи, линейка, текст; магнит к OHLC; сохранение рисунков по символу.
- На графике: сделки (маркеры), цена входа, ликвидации, TP/SL, лимитные и условные ордера, сетки ботов.
- Перетаскивание линий лимитных/условных ордеров и TP/SL прямо на графике; правый клик — меню: подставить цену в форму ордера, **открыть колл/пут по рынку на страйке у этого уровня** (купить/продать, выбор экспирации и объёма), **ценовой алерт** (пауза симуляции и остановка перемотки при касании), скопировать цену.
- **Все позиции в одном месте**: кнопка «Позиции» в шапке (или клавиша **P**) и вкладка «Все позиции» — перпетуалы, опционы, спот-монеты (вкл. xStocks) и боты, с закрытием 25% / 50% / 100%, TP/SL и переходом к инструменту.
- Форма запоминает выбор: тип ордера (лимит / рыночный / условный), единицы (монеты / USDT), TIF, тип ордера опционов, последнюю вкладку нижней панели. В форме фьючерса — **оценка цены ликвидации** до открытия.
- Стакан (смоделированный), лента, тикер 24ч, таймер funding, обзор рынков, калькулятор PnL / цены цели / ликвидации.
- Активы и **аналитика**: кривая капитала против buy&hold, просадка, Шарп, Сортино, Калмар, CAGR, win rate, profit factor, распределение сделок, PnL по дням и месяцам, по инструментам; экспорт CSV/JSON.
- Сохранение/восстановление сессий в браузере (с автосохранением), импорт/экспорт JSON.

## Как запустить (простой способ)

Это веб-приложение: отдельного .exe нет, программа открывается в браузере, а маленький локальный сервер на вашем компьютере подгружает данные с биржи.

1. Установите **Node.js** (один раз): https://nodejs.org → кнопка **LTS** → установить с настройками по умолчанию.
2. Скачайте проект: на странице репозитория выберите ветку `claude/trading-backtester-platform-e9bong` → зелёная кнопка **Code** → **Download ZIP** → распакуйте.
3. **Windows:** дважды кликните `start.bat`. **macOS/Linux:** запустите `./start.sh`.
4. Первый запуск 1–3 минуты (установка и сборка), дальше — несколько секунд. Браузер откроется сам на http://localhost:8080. Окно с сервером не закрывайте, пока работаете.

После обновления кода удалите папку `dist`, чтобы приложение пересобралось.

## Как пользоваться

1. **Сессии** → выберите период (пресет или свои даты), базовый интервал (точность исполнения: 1м … 1Д), депозит и инструменты. Нажмите «Начать сессию».
2. Управление временем — панель под шапкой: ▶/❚❚ (**пробел**), «+1 бар» (**→**), «+1 свеча» (**Shift+→**), скорость, перемотка к дате, клик по полосе прогресса, «⏪ Назад» к контрольной точке. Правый клик по графику → «Алерт» — симуляция остановится, когда цена дойдёт до уровня.
3. Торгуйте на вкладках **Деривативы**, **Спот** (там же xStocks и золото), **Опционы**; запускайте ботов на вкладке **Торговые боты**. Все открытые позиции — кнопка «Позиции» в шапке (**P**).
4. Итоги — во вкладках **Активы** и **Аналитика**.

Символы, не выбранные при старте, догружаются прямо из терминала (список символов → «загрузить»).

## Источники данных

| Источник | Что загружается | Примечание |
|---|---|---|
| **Bybit** (по умолчанию) | свечи и история funding USDT-перпетуалов, свечи спота xStocks/золота, спецификации инструментов | API Bybit недоступен из некоторых регионов (США и др.) |
| OKX | свечи и funding (~3 мес.) | автоматический фолбэк; есть все крипто-активы, кроме MNT/TON, TradFi-перпетуалы, перпетуалы на акции (цена для xStocks) и спот XAUT/PAXG |
| Binance Futures | свечи и funding | фолбэк для крипто-активов |
| Синтетика | детерминированный генератор | офлайн-режим для проверки логики |
| Deribit | индекс DVOL (BTC/ETH) | только при выборе IV-модели «DVOL» |

Если основной источник недоступен, автоматически используется следующий — в тикере видно, откуда пришли данные. Загруженные свечи кешируются в IndexedDB, повторный запуск той же сессии мгновенный. Запросы идут через локальный прокси (`/proxy/*` в Vite или `server/server.mjs`), чтобы обойти CORS.

## Модель исполнения и допущения

- **Движение цены внутри свечи**: для бычьей свечи Open→Low→High→Close, для медвежьей Open→High→Low→Close (опционально — пессимистичный порядок против позиции). Лимитные ордера исполняются при касании цены (мейкер), рыночные — по последней цене ± проскальзывание (тейкер). Все события — ордера, TP/SL, трейлинги, ликвидации — обрабатываются строго в порядке достижения цены, поэтому, например, сеточный бот может сделать несколько сделок за одну свечу.
- **Mark price ≈ Last price** (история mark price не используется).
- **Стакан** в истории недоступен — отображаемая глубина смоделирована; объём ордеров не влияет на цену исполнения.
- **Спот** использует цены перпетуала того же актива; спотовые монеты не учитываются как залог для деривативов.
- **Опционы**: IV — модель (реальные исторические котировки опционов Bybit публично недоступны). Маржа шорта: IM = mark + max(15% × S − OTM, 10% × S), MM = mark + 7.5% × S (настраивается). Расчёт на экспирации — по цене базового перпетуала на момент 08:00 UTC (при базовом интервале 1Д — по цене открытия дня). Комиссия: 0.03% от цены базового актива, но не более 7% премии; поставка — 0.015%.
- **Ликвидация**: позиция закрывается по цене ликвидации, остаток поддерживающей маржи уходит в «страховой фонд» — итоговый убыток равен марже (изолированная) либо кросс-капитал обнуляется (кросс).
- Перемотка назад — через контрольные точки (кнопка «⏪ Назад»): они создаются автоматически каждые сутки (неделю для крупных интервалов), при ваших сделках и перед перемоткой вперёд. Для долгого хранения используйте сохранения сессий.

## API стратегий (кратко)

```js
const PARAMS = { fast: 12, slow: 26, leverage: 3 };

function init(ctx, p) {
  ctx.setLeverage(p.leverage);
}

function onBar(ctx, p) {                 // вызывается на закрытии свечи таймфрейма
  const f0 = ctx.ta.ema(p.fast), f1 = ctx.ta.ema(p.fast, 1);   // offset 1 — предыдущая свеча
  const s0 = ctx.ta.ema(p.slow), s1 = ctx.ta.ema(p.slow, 1);
  ctx.plot('EMA fast', f0);
  if (ctx.ta.crossover(f0, f1, s0, s1)) ctx.long({ percent: 50, sl: ctx.close * 0.97 });
  if (ctx.ta.crossunder(f0, f1, s0, s1)) ctx.exit();
}
```

Полная справка — кнопка «Справка API» в лаборатории.
