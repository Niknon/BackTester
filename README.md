# BackTester — симулятор биржи Bybit на исторических данных

Веб-терминал в стиле Bybit, в котором торговля идёт **на истории**: время симуляции
движется свеча за свечой (с паузой, шагами и перемоткой), а будущее скрыто. Можно
торговать вручную, запускать торговых ботов и прогонять собственные стратегии.

## Возможности

### Фьючерсы (USDT-перпетуалы)
- Плечо от 1x до максимума Bybit для инструмента, **кросс** и **изолированная** маржа.
- Ордера: лимитные, рыночные, условные (стоп-маркет / стоп-лимит), GTC / IOC / FOK / Post-Only, Reduce-Only.
- TP/SL при открытии и на позицию, **трейлинг-стоп**, частичное и полное закрытие (по рынку и лимитом), изменение маржи изолированной позиции.
- Комиссии мейкер/тейкер (по умолчанию как у Bybit VIP0: 0.02% / 0.055%), проскальзывание.
- **Funding** по реальной истории ставок (выплаты каждые 8 ч или по фактическому расписанию).
- **Ликвидации**: изолированные — по цене ликвидации с потерей маржи; кросс — по коэффициенту поддерживающей маржи аккаунта (MMR первого тира = IMR<sub>min</sub>/2, как у Bybit).
- Единый торговый аккаунт (UTA): капитал, доступный баланс, IM/MM, MMR.

- **Длинная история акций США** — с Yahoo Finance (пресеты «5 лет», «10 лет»). **Внутридневная история за годы** — с Dukascopy: Yahoo отдаёт 1ч только за 2 года, а 5–30 мин — за 60 дней, поэтому более старые часовые и минутные свечи загрузчик автоматически берёт из архива Dukascopy (~680 акций и ETF США — с 2017 г., S&P 500 и Nasdaq-100 — с 2012, золото — с 2003, серебро, нефть, газ, медь), приводит их к сплитам по Yahoo и сообщает, какой период откуда загружен. Ошибочные принты пре/постмаркета Yahoo (ложные «шпильки» на десятки процентов) отфильтровываются. **Сплиты**: Yahoo поправляет внутридневные свечи только на сплиты не позже дня конца запрошенного окна — кусок истории, закончившийся до сплита, приходит в «сырых» ценах (NFLX до 10:1 в ноябре 2025 — ~1100 вместо ~110). Загрузчик досчитывает такие сплиты сам, кэш свечей привязан к последнему сплиту актива (после нового сплита старые куски перекачиваются), а итоговая история любой акции из любого источника (Yahoo, Dukascopy, перпетуалы бирж) сверяется по дням с дневными ценами Yahoo: дни, где цена отличается ровно в «сплитовое» число раз, исправляются, и об этом сообщается при загрузке. В результатах опционной стратегии отдельно предупреждается о скачках цены больше чем в 1.5 раза за одну свечу — так выглядит ошибка данных. Любую другую акцию/ETF США можно добавить по тикеру — в «Сессиях» («+ Акция США») или прямо во время сессии: в любом списке символов (терминал, формы ботов) введите тикер, например DIS, и выберите «＋ Добавить акцию / ETF США».
- **Комбо-бот из крипты и акций**: шаблоны портфелей (BTC + S&P 500, BTC + золото + S&P, крипта + Nasdaq, Mag-7 + BTC, крипто-акции vs BTC) и график сравнения активов портфеля (=100 на начало окна) с линией портфеля без ребалансировки.
- **Модельные опционы** на все TradFi-активы (акции, ETF, индексы, сырьё) — на странице «Опционы» → «Акции США и др. (симуляция)»: та же модель цены, маржа, экспирация, стратегии и меню графика, что и у опционов Bybit.
- У акций есть ночные и выходные разрывы: стопы и лимиты, «перепрыгнутые» гэпом, исполняются по цене открытия. Комбо-бот можно собрать из акций и крипты вместе.

### Опционы
- Все базовые активы опционов Bybit (на сентябрь 2026):
  - крипто: **BTC, ETH, SOL, XRP, DOGE, MNT, HYPE**;
  - **Perp Options** на TradFi-перпетуалы: **NVDA, TSLA, QQQ, SPCX (SpaceX), SOXL, MU, SKHY (SK Hynix), SNDK (SanDisk)**.
- Экспирации как у Bybit: 3 дневные, 3 недельные (пятница), 3 месячные (последняя пятница), для BTC/ETH — квартальные; всё в 08:00 UTC. Символы вида `BTC-26SEP26-90000-C-USDT`.
- Цепочка страйков (bid / mark / ask, IV, дельта, гамма, вега, тета). Клик в любом месте строки выбирает колл (левая половина) или пут (правая); тикет справа: тип колл/пут, экспирация, страйк (◀ ▶, ITM/ATM/OTM), две большие кнопки **Купить по Ask / Продать по Bid**, объяснение сделки простыми словами и PnL до открытия.
- Цена — Блэк–Шоулз; IV = реализованная волатильность × премия + временная структура + улыбка (скос и кривизна). Волатильность — экспоненциально сглаженная по времени (без заглядывания в будущее): текущий уровень с полупериодом ~11 торговых дней (как RiskMetrics λ = 0.94) и долгосрочный — с полупериодом ~полгода; дисперсия до экспирации — путь от текущего уровня к долгосрочному за ~месяц: σ²(T) = slow² + (fast² − slow²)·(1 − e^(−κT))/(κT). Раньше IV бралась из окна 7 дней: на дневных свечах это 5 доходностей, и в тихую неделю IV NVDA падала до 8% — покупка «дешёвых» опционов (например, с фильтром по IV-рангу) давала +60…80% к премии на ровном месте; теперь доход стрэддла по корзинам IV почти ровный. **Часы опциона**: у крипты время до экспирации и волатильность считаются круглосуточно, у акций, ETF, индексов и сырья — по будням (в выходные торгов нет, цена стоит — опцион не дешевеет «за счёт» выходных, а недельный опцион с понедельника по пятницу не недооценивается), причём внутри дня время идёт по профилю активности актива: час торговой сессии «длиннее» ночного (профиль считается по истории самого актива — какая доля дневной дисперсии приходится на каждый час; это форма распределения, а не уровень волатильности). Иначе опцион, купленный утром до сессии и проданный вечером, систематически переоценивался бы к вечеру. У акций и сырья нет экспираций в субботу и воскресенье. **Отчёты компаний**: даты квартальных отчётов берутся из SEC EDGAR (8-K, п. 2.02; у иностранных эмитентов — 6-K с квартальными результатами, по имени документа). Если за часть периода дат нет (у иностранных эмитентов документы не всегда распознаются), результаты стратегии об этом предупреждают. Скачок цены на отчёте не смешивается с обычной волатильностью: свечи реакции (постмаркет, ночь и открытие следующей сессии — или премаркет и открытие, если отчёт до открытия) исключаются из реализованной волатильности и профиля часов, а ожидаемый скачок добавляется к дисперсии тех экспираций, которые захватывают отчёт: σ²·T + скачок. Размер скачка — среднее по последним 8 уже прошедшим отчётам этого актива (в дневных дисперсиях, без заглядывания в будущее), пока истории мало — априорно «как 2.5 обычных дня». Поэтому недельный опцион перед отчётом дорогой, а после отчёта IV возвращается к обычной — как на реальном рынке. Без этого покупка опционов перед отчётами давала бы систематическую «бесплатную» прибыль (на NVDA за 5 лет сделки через отчёт приносили в среднем +120…260% к премии против +20…30% у остальных). На странице опционов показывается ближайший отчёт и заложенное движение. Временная стоимость считается до момента, когда биржа фактически рассчитывает экспирацию (начало свечи, в которой 08:00: на дневных свечах — 00:00), и экспирация рассчитывается по цене **на этот момент — последнему закрытию**, а не по открытию следующей свечи: у акций открытие дневной свечи — это 13:30 UTC с гэпом за ночь или выходные, и опцион, купленный в пятницу на понедельник, стоил почти ноль, а выплату получал с гэпа выходных (стратегии зарабатывали 10^40 за 10 лет). **Праздники биржи** (будни без свечей в данных) — как выходные: время опциона в них не идёт, иначе продавец получал бы премию за день без торгов. «Однодневные» экспирации акций — три ближайших рабочих дня. Стратегия не берёт экспирации, до расчёта которых не осталось торгового времени. Для BTC/ETH можно использовать индекс **DVOL** (Deribit). Улыбка безарбитражная: на крыльях IV выходит на плато, поэтому дальний OTM-опцион никогда не стоит дороже ближнего (проверяется тестом на сетке сроков и волатильностей); спред bid/ask считается от временной стоимости, так что у глубоких ITM bid не уходит ниже внутренней стоимости.
- Шаг страйков — как на биржах: у крипто-опционов как на Bybit (BTC: дневные 500, недельные и месячные 1 000, дальние 2 000; у денег мелкий шаг, на крыльях крупный), у модельных опционов на акции — как на биржах США (AAPL: $1 / $2.5 / $5).
- Покупка и продажа (шорт) опционов с маржой, европейская экспирация с поставкой деньгами и комиссией поставки.
- **Опционные стратегии в один клик** (вкладка «Опционные стратегии»): колл/пут-спреды (бычьи и медвежьи, дебетовые и кредитные), стрэддл и стрэнгл (лонг/шорт), календарные спреды, бабочка, железный кондор. Выбор экспирации (для календарей — ближней и дальней), центрального страйка и ширины, объёма; таблица ног с ценами, кредит/дебет, оценка маржи, профиль выплат, макс. прибыль/убыток, безубыточность, сценарии. Все ноги исполняются сразу по рынку; если одна не проходит — остальные откатываются.
- Вкладка **«Другие стратегии»**: обратный кондор, железная бабочка (шорт/лонг), бабочка на путах, шорт-бабочка, бабочка с ломаным крылом, кондор на коллах, рейшио-спреды 1×2, бэкспреды, риск-реверсалы, синтетические лонг/шорт, нефритовая ящерица, чайка, стрэп, стрип, гатс, ёлка, диагональные спреды, бокс-спред, а также стратегии с перпетуалом — покрытый колл, защитный пут, коллар.
- Профиль выплат (на экспирации и T+0), греки портфеля, **конструктор стратегий** (стрэддл, стрэнгл, спреды, железный кондор, бабочка, риск-реверсал…), график улыбки и временной структуры IV.

### Торговые боты (каждый — в изолированном суб-аккаунте)
- **Спотовый грид** — арифметическая/геометрическая сетка, цена запуска, TP/SL, продажа монет при остановке.
- **Фьючерсный грид** — лонг / шорт / нейтральный, с плечом, TP/SL по цене и по ROI.
- **Фьючерсный комбо-бот (ребалансировка)** — портфель лонг/шорт перпетуалов с целевыми весами; ребалансировка по времени или по отклонению весов.
- **DCA** — регулярные покупки с фиксацией прибыли.
- **Фьючерсный мартингейл** — усреднения с множителем, TP от средней, цикличность.
- «AI-параметры» (диапазон и число сеток по недавней истории — без будущих данных).
- **Быстрый бэктест бота** в отдельной копии биржи (с текущего момента или с начала периода) — с отчётом и кривой капитала.
- **Сетка на графике**: при настройке грид-бота график сразу показывает все уровни (покупки / продажи / пустой уровень), границы, цену запуска и TP/SL — границы можно **тянуть мышью**. Для мартингейла — уровни усреднений и средняя, для DCA — «покупать ниже». Во вкладке «Запущенные» — график выбранного бота с живыми ордерами сетки, его позицией и сделками; в «Подробнее» → «На графике» — то же для остановленных ботов.

### Лаборатория стратегий
- Редактор JavaScript (CodeMirror) с шаблонами: пересечение EMA, RSI, пробой Дончиана с ATR-трейлингом, Supertrend, Bollinger + MACD.
- API: индикаторы (`ctx.ta.*`), ордера (`ctx.buy/sell/long/short/exit`), TP/SL, трейлинг, плечо, логи и плоты.
- Исполнение на базовом интервале с тем же движком (комиссии, funding, ликвидации).
- **Оптимизация параметров** перебором по сетке с сортировкой по Шарпу / доходности / PF / Калмару.

### Портфельная стратегия «Пробой лидеров» (Leaders Breakout)
Вкладка «Стратегии» → «Портфельная: «Пробой лидеров»». Реализация по спецификации буквально (правила не «улучшались», параметры не подбирались):
- **Рынки**: США (S&P 500, Yahoo Finance, цены скорректированы на сплиты и дивиденды, шаг — 1 акция), Мосбиржа (база MOEXBMI, MOEX ISS, режим TQBR, цены скорректированы на сплиты и дивиденды, шаг — лот), крипта (топ-30 монет к USDT, спот Binance, при недоступности — OKX). Бенчмарк: ^GSPC / IMOEX / BTC/USDT.
- **Параметры** — `config.yaml` прямо в редакторе (по умолчанию — значения из спецификации, для крипты — окна 365/30/[90, 180] и комиссия 0.1%), вселенная — `universe.txt` (редактируется, загружается из файла).
- **Правила**: режим рынка по бенчмарку (SMA50/200), фильтр лидеров (тренд SMA50 > 150 > 200, рост SMA200, ≤ 25% от годового максимума, доходность 63/126 дней в верхних 20% вселенной), вход на пробое 20-дневного максимума при сжатии волатильности и объёме ≥ 1.5×, ранжирование по силе; размер — 1% риска (0.5% при просадке ≥ 10%), стоп 2×ATR14, до 5 позиций, ≤ 20% капитала; трейлинг по 10-дневному минимуму, тайм-стоп 10 баров, одна докупка ½ объёма при +1.5R со стопом в безубыток; остановка при просадке 20%.
- **Исполнение**: решения — по закрытию дня, исполнение — на открытии следующего (выходы → гэпы через стоп → докупки → входы), внутри дня — только защитные стопы; проскальзывание и комиссия с каждой сделки.
- **Отчёт**: CAGR, просадка и её длительность, Sharpe, MAR, доходность по годам и месяцам против бенчмарка, сделки (win rate, R, матожидание, profit factor, удержание, загрузка капитала, серия убытков), проверка цели +100% в год, pass/fail-проверки, срабатывания предохранителей, предупреждения (ошибка выжившего и пр.). Выгрузка `summary.md`, `trades.csv`, `equity.csv`, `equity.png`.
- **Сканер**: по последним данным и вашим `positions.csv` / `account.yaml` — действия на завтра по открытым позициям (держать / выйти с причиной / докупить N, новый стоп, уровень трейлинга) и новые входы по рангу (цена, стоп, количество, доля капитала). Те же функции правил, что в бэктесте. Выгрузка `signals/ГГГГ-ММ-ДД.md`.
- **Чувствительность**: сетка breakout_lookback {15, 20, 30} × atr_stop_mult {1.5, 2.0, 2.5} × trail_lookback {10, 20} — проверка устойчивости, не подбор.
- Данные кешируются в браузере: S&P 500 за 12 лет загружается ~15 с, повторный прогон после правки config.yaml — ~1 с.
- Дивиденды Мосбиржи: MOEX ISS перестал бесплатно отдавать их историю, поэтому источники идут цепочкой — MOEX ISS (если снова начнёт отдавать) → **dohod.ru** (история с 2000-х, суммы уже пересчитаны на сплиты и консолидации — в тех же единицах, что свечи ISS) → **smart-lab.ru** (доля дивиденда от цены; заодно отличает «дивидендов не было» от «источник недоступен»). День отсечки — по правилам расчётов Мосбиржи: T+1 с 31.07.2023, T+2 раньше, T0 до сентября 2013; торги выходного дня и праздничные сессии (с марта 2025 г.) рассчитываются со следующим рабочим днём, а их правила менялись, поэтому из таких сессий отсечкой считается та, где гэп открытия наибольший. Проверка на свечах ISS 50 бумаг за 2014–2026 гг.: гэп цены приходится на рассчитанный день в 96% выплат больше 2% цены. Объявленные, но ещё не наступившие выплаты не применяются. В отчёте указано, сколько бумаг взято из каждого источника и сколько поправок применено; если ни один источник не ответил — предупреждение со списком бумаг. Данные кешируются в браузере на 7 дней.

### Опционная стратегия (настройки — прямо в интерфейсе)
Вкладка «Стратегии» → «Опционная стратегия». Без кода и конфигов: всё задаётся ползунками и переключателями, результат пересчитывается автоматически через полсекунды после изменения (можно выключить).
- **Несколько активов сразу**: отметьте любые активы сессии с опционами — по каждому стратегия ведёт свои конструкции по тем же правилам, счёт и маржа общие; итоги по активам, бенчмарк — равновесная корзина, на графике и в «Входе сейчас» — переключатель актива.
- **Конструкции** (16): железный кондор, шорт стрэнгл / стрэддл, продажа пута / колла, кредитные и дебетовые спреды, железная бабочка, покрытый колл, защитный пут, лонг стрэддл / стрэнгл, покупка колла / пута.
- **Страйки и срок**: основные ноги — по целевой дельте (или ATM), крылья — на заданном % от цены или по дельте; экспирация — «не позже N дней» (по умолчанию: недельная позиция заканчивается до следующего недельного входа в любой день недели) или «ближайшая к N дням».
- **Когда входить**: каждый день / по будням / раз в неделю (день недели), час входа UTC, максимум одновременно открытых конструкций на актив (конструкция, которая рассчитывается экспирацией на ближайшей свече, лимит уже не занимает).
- **Размер**: по риску (макс. убыток на экспирации ≤ X% капитала), по номиналу, по доле средств под маржу или фиксированное количество. Перед входом проверяется, хватает ли средств на премию и маржу всех ног; если нет — вход пропускается (а не делается и откатывается с потерей на спреде), это видно в «Пропущенных входах». **Потолок на конструкцию** (по умолчанию включён, 1 000 000 USDT премии и маржи): ликвидность реального рынка конечна, а без потолка размер растёт вместе со счётом и сложный процент за несколько лет уходит в триллионы; сколько входов упёрлось в потолок — видно в результатах.
- **Выход**: по умолчанию — держать до экспирации (расчёт по цене в 08:00 UTC). По желанию — тейк-профит и стоп-лосс в % от премии (включаются галочками, по умолчанию выключены), закрытие за N дней до экспирации, по дельте проданной ноги, при пробое проданного страйка.
- **Фильтры**: диапазон ATM IV, IV-ранг за N дней (только по прошлым данным), цена выше/ниже SMA.
- **Дельта-хедж** перпетуалом с допуском и минимальным интервалом между сделками.
- **Результаты**: доходность против buy&hold, просадка, Шарп, процент прибыльных, полученная премия, итог хеджа, итог конструкций, заставших отчёт компании, разбивка по причинам выхода и пропущенным входам; график актива со страйками каждой конструкции и отметками входа/выхода; таблица сделок с ногами (цены, IV и дельта входа, комиссии, как закрыта), CSV; журнал решений.
- **Вход сейчас** — какие ноги стратегия открыла бы в текущий момент сессии, с профилем выплат, кредитом/дебетом, макс. прибылью/убытком и точками безубыточности; обновляется при любом изменении настроек.
- **Перебор параметра** (дельта, срок, день входа, тейк, стоп, ширина крыла, …) — таблица результатов, лучшее значение применяется одним кликом.
- **Сверка**: сумма результатов конструкций, хеджа, откатов отклонённых входов и прочего (funding) равна изменению капитала биржи — проверяется тестами и перебором случайных настроек на 5 годах истории BTC/ETH/SOL.
- Пресеты (недельный кондор, стрэнгл 45/21, продажа пута, ежедневный кондор, покрытый колл, стрэддл с хеджем, пут-спред при высокой IV) и сохранение своих наборов.
- Прогон — в отдельной копии биржи на данных сессии: те же цены опционов, спред, комиссии, маржа, экспирация и ликвидации, что при ручной торговле; решения только по закрытым свечам.

### Визуал и инструменты
- Графики TradingView lightweight-charts v5: свечи / Хейкен-Аши / бары / линия, таймфреймы от базового до недели.
- Индикаторы: MA, EMA, Bollinger, VWAP, SuperTrend, Donchian, объём, RSI, MACD, Stochastic, ATR, CCI, OBV, ADX/DMI (с параметрами, в отдельных панелях).
- Рисование: трендовая, луч, горизонталь, вертикаль, прямоугольник, Фибоначчи, линейка, текст; магнит к OHLC; сохранение рисунков по символу.
- На графике: сделки (маркеры), цена входа, ликвидации, TP/SL, лимитные и условные ордера, сетки ботов.
- Перетаскивание линий лимитных/условных ордеров и TP/SL прямо на графике.
- **Правый клик по графику** — меню с вкладками (последняя открытая запоминается), всё относительно уровня клика:
  - **Фьючерс / Спот** — сумма в USDT или монетах (10/25/50/100% от доступного); на уровне: лимит или стоп в нужную сторону (выше цены — «Лимит шорт» и «Стоп лонг», ниже — «Лимит лонг» и «Стоп шорт»); рыночные покупка/продажа; при открытой позиции — Stop Loss / Take Profit на этом уровне и закрытие лимитом.
  - **Опцион** — колл/пут по рынку на страйке у уровня (купить/продать, экспирация, объём); страйк можно сдвинуть кнопками − / + на шаг, видны марк-цены и IV; страйк и безубыточность покупки колла/пута сразу показываются на графике.
  - **Стратегия** — любая из опционных стратегий (основные и другие) с центром на уровне клика (сдвиг − / +): ширина, экспирация, объём, ноги с ценами, кредит/дебет, макс. прибыль/убыток, точки безубыточности, маржа; **страйки ног и точки безубыточности заранее рисуются на графике** (шкала подстраивается, чтобы все уровни были видны); открытие одним действием.
  - **Прочее** — подставить цену в форму ордера, **ценовой алерт** (пауза симуляции и остановка перемотки при касании), скопировать цену, удалить алерты.
- **Новости и события на графике** (кнопка 📰 на панели графика включает/выключает слой, ▾ — настройки), как на графиках Bybit/TradingView:
  - экономический календарь (США, по выбору — Еврозона, Великобритания, Япония, Китай; только важные или + средние): CPI, NFP, решения ФРС и ЕЦБ, PMI, ВВП и др. — с русскими названиями и значениями «факт / прогноз / пред.»;
  - для акций — даты отчётов (до открытия / после закрытия), экс-дивидендные даты и сплиты; для крипты — ключевые события (халвинги, обновления Ethereum, ETF, крах FTX и LUNA и т. д.);
  - **прошлые и будущие события без заглядывания в будущее**: прошедшие — с фактическим значением; после текущего момента симуляции видны только события, известные заранее (календарь — с прогнозом, но без факта, с обратным отсчётом), внезапные — только после того, как случились; ближайшие события за правым краем — в маркере «→»;
  - уведомление при выходе важной новости во время воспроизведения и опциональная **пауза за бар до важной новости**.
- **Все позиции в одном месте**: кнопка «Позиции» в шапке (или клавиша **P**) и вкладка «Все позиции» — перпетуалы, опционы, спот-монеты (вкл. xStocks) и боты, с закрытием 25% / 50% / 100%, TP/SL и переходом к инструменту.
- Funding можно отключить при настройке сессии или прямо во время неё (⚙ на панели времени).
- Поиск инструментов с группами (крипто / акции и TradFi / с опционами).
- Уведомления: на экране не больше трёх сразу (не перекрывают форму ордера), а **история всех уведомлений сессии — под 🔔 в шапке** (со временем симуляции). Экспирация нескольких опционов (например, всех ног стратегии) — **одно сводное уведомление**: цена расчёта, каждая нога (в деньгах / вне денег, PnL) и итог. Открытие стратегии — тоже одно уведомление со всеми ногами, ценами, премией и комиссиями.

## Как запустить (простой способ)

Это веб-приложение: отдельного .exe нет, программа открывается в браузере, а маленький локальный сервер на вашем компьютере подгружает данные с биржи.

1. Установите **Node.js** (один раз): https://nodejs.org → кнопка **LTS** → установить с настройками по умолчанию.
2. Скачайте проект: на странице репозитория выберите ветку `claude/trading-backtester-platform-e9bong` → зелёная кнопка **Code** → **Download ZIP** → распакуйте.
3. **Windows:** дважды кликните `start.bat`. **macOS/Linux:** запустите `./start.sh`.
4. Первый запуск 1–3 минуты (установка и сборка), дальше — несколько секунд. Браузер откроется сам на http://localhost:8080. Окно с сервером не закрывайте, пока работаете.

После обновления кода удалите папку `dist`, чтобы приложение пересобралось.

## Модель исполнения и допущения

- **Движение цены внутри свечи**: для бычьей свечи Open→Low→High→Close, для медвежьей Open→High→Low→Close (опционально — пессимистичный порядок против позиции). Лимитные ордера исполняются при касании цены (мейкер), рыночные — по последней цене ± проскальзывание (тейкер). Все события — ордера, TP/SL, трейлинги, ликвидации — обрабатываются строго в порядке достижения цены, поэтому, например, сеточный бот может сделать несколько сделок за одну свечу.
- **Mark price ≈ Last price** (история mark price не используется).
- **Стакан** в истории недоступен — отображаемая глубина смоделирована; объём ордеров не влияет на цену исполнения.
- **Спот** использует цены перпетуала того же актива; спотовые монеты не учитываются как залог для деривативов.
- **Опционы**: IV — модель (реальные исторические котировки опционов Bybit публично недоступны). Маржа шорта: IM = mark + max(15% × S − OTM, 10% × S), MM = mark + 7.5% × S (настраивается). Расчёт на экспирации — по цене базового перпетуала на момент 08:00 UTC (при базовом интервале 1Д — по цене открытия дня). Комиссия: 0.03% от цены базового актива, но не более 7% премии; поставка — 0.015%.
- **Ликвидация**: позиция закрывается по цене ликвидации, остаток поддерживающей маржи уходит в «страховой фонд» — итоговый убыток равен марже (изолированная) либо кросс-капитал обнуляется (кросс).
- Перемотка назад — через контрольные точки (кнопка «⏪ Назад»): они создаются автоматически каждые сутки (неделю для крупных интервалов), при ваших сделках и перед перемоткой вперёд. Для долгого хранения используйте сохранения сессий.

## API стратегий (кратко)

```js
const PARAMS = { fast: 12, slow: 26, leverage: 3 };

function init(ctx, p) {
  ctx.setLeverage(p.leverage);
}

function onBar(ctx, p) {                 // вызывается на закрытии свечи таймфрейма
  const f0 = ctx.ta.ema(p.fast), f1 = ctx.ta.ema(p.fast, 1);   // offset 1 — предыдущая свеча
  const s0 = ctx.ta.ema(p.slow), s1 = ctx.ta.ema(p.slow, 1);
  ctx.plot('EMA fast', f0);
  if (ctx.ta.crossover(f0, f1, s0, s1)) ctx.long({ percent: 50, sl: ctx.close * 0.97 });
  if (ctx.ta.crossunder(f0, f1, s0, s1)) ctx.exit();
}
```

Полная справка — кнопка «Справка API» в лаборатории.
